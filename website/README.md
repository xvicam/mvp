# VICAM Innovation Fest Showcase

This is the official VICAM (Vehicle-Integrated Cyclist Alert Module) product showcase site built with React and Tailwind CSS. It highlights the problem, solution, animated demo placeholders, and links to the research poster.

## Features

- Light and dark mode toggle (default is light).
- Hero overview, problem/solution narrative, and animated demo section.
- Poster PDF link at `/VICAM_Poster_A1.pdf`.
- Team section with LinkedIn and GitHub placeholders.
- Feedback form for live demos.

## Quick start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Poster link

The poster PDF lives in `public/VICAM_Poster_A1.pdf` so it can be linked directly from the UI.
